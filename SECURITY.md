# Security policy

## Reporting a vulnerability

Report a vulnerability privately through a GitHub security advisory at
<https://github.com/musher-dev/sdk-agent-skills/security/advisories/new>, not in a public issue. We acknowledge a
report within three working days and agree a disclosure date with you once a fix is ready.

The skill tells agents never to ask for an API key in chat and never to pass one on a command line. Report any
instruction here that could lead an agent to expose a credential, run something the user did not approve, or spend
the user's balance without asking.
